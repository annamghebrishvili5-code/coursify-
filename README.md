# Coursify — ონლაინ სასწავლო კურსების პლატფორმა

Coursify არის სასწავლო ვებპროექტი, რომელიც მომხმარებელს კურსების მოძებნის, ფილტრაციის, დეტალების ნახვის, ფავორიტებში შენახვისა და კალათაში დამატების შესაძლებლობას აძლევს.

## გაშვება
1. ჩამოტვირთეთ ZIP და ამოარქივეთ.
2. გახსენით `Coursify_Final` საქაღალდე.
3. ორჯერ დააწკაპუნეთ `index.html` ფაილზე.
4. საიტი გაიხსნება თანამედროვე ბრაუზერში. Node.js, npm, Vite ან ინტერნეტი ლოკალური გაშვებისთვის საჭირო არ არის.

## გვერდები
- `index.html` — მთავარი გვერდი
- `courses.html` — კატალოგი, ძებნა და ფილტრები
- `course.html?id=web-basics` — კურსის დეტალები (გახსენით კატალოგიდან)
- `favorites.html` — ფავორიტები
- `cart.html` — კალათა
- `about.html` — ჩვენ შესახებ
- `contact.html` — საკონტაქტო ინფორმაცია და ვალიდაციის მქონე ფორმა

## ტექნოლოგიები
- HTML5 — სემანტიკური გვერდის სტრუქტურა
- CSS3 — CSS ცვლადები, Flexbox, Grid, responsive media queries
- Vanilla JavaScript (ES6+) — DOM-ის განახლება, ივენთები, ძებნა, ფილტრაცია და ფორმის ვალიდაცია
- localStorage — კალათისა და ფავორიტების შენახვა ბრაუზერში
- Git/GitHub — ვერსიების კონტროლისა და გაზიარების დაგეგმილი პროცესი

## მნიშვნელოვანი შენიშვნები
- პროექტი Vanilla HTML/CSS/JavaScript-ზეა და არ იყენებს React-ს ან build ინსტრუმენტს.
- კალათა სადემონსტრაციო ფუნქციაა; რეალური გადახდა არ მუშავდება.
- საკონტაქტო ტელეფონი, ელფოსტა და მისამართი სასწავლო დემოსთვის მოფიქრებულია. `hello@coursify.example` განკუთვნილია მაგალითისთვის და რეალური საფოსტო ყუთი არ არის.
- საკონტაქტო ფორმა ამოწმებს ველებს ბრაუზერში, მაგრამ შეტყობინებას სერვერზე არ აგზავნის.
- GitHub და Vercel ბმულები README-ში უნდა დაემატოს მხოლოდ რეალური გამოქვეყნების შემდეგ.

## GitHub Pages ფაილების განლაგება
ყველა HTML ფაილი და `style.css`, `app.js`, `data.js` მთავარ საქაღალდეშია. HTML ფაილებში აქტივების მისამართები ფარდობითია, ამიტომ მუშაობს GitHub Pages-ის `/coursify/` მისამართზეც.
